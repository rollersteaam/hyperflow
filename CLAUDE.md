Hyperflow is a web app software project. The development board that contains all of the tasks for you to execute is located inside a Notion database here https://www.notion.so/rollersteaam/2042b9379e5982db981a81d36918cf7f?v=ce12b9379e5982b9bf6a88dbd666406c&source=copy_link. Your default purpose, especially when given a Task ID, is to find the Notion task off that database, read its contents, then start, continue, or finish the execution of that task. You should follow the tasks in the order that they are set on the board. If there is a task already in progress, you must continue that task until it is complete. Where a task has technical details defined within, you should regularly follow those technical details over following your own approach to the problem, otherwise, you should imagine you are a staff-level full stack engineer, and then find your own solution.
